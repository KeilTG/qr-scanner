# QR-сканер

Веб-приложение, которое сканирует QR-коды с камеры (телефона или ноутбука) или с загруженной картинки. Результат выводится в формате JSON на странице и в консоль браузера.

Распознаёт код сам браузер с помощью библиотеки [jsQR](https://github.com/cozmo/jsQR). Сервер нужен только для того, чтобы отдать страницу по **HTTPS**: без него браузеры не дают доступа к камере (кроме `localhost`).

---

## Быстрый старт

### Вариант 1 — Docker (рекомендуется)

```bash
docker compose up -d --build
```

Открыть: <https://localhost:8443>

Чтобы зайти с телефона (он должен быть в той же Wi‑Fi сети), создайте рядом с `docker-compose.yml` файл `.env` с IP-адресом компьютера (узнать его можно командой `ipconfig`, строка «IPv4-адрес»):

```
HOST_IP=192.168.1.10
```

и перезапустите: `docker compose up -d`. Потом откройте на телефоне `https://192.168.1.10:8443`.

> Сертификат создаётся при первом запуске и сохраняется в docker-томе `certs`. Если вы поменяли `HOST_IP`, удалите том, чтобы сертификат пересоздался:
> `docker compose down -v && docker compose up -d`

Полезные команды:

| Команда | Что делает |
|---|---|
| `docker compose logs -f` | показать логи и адреса для подключения |
| `docker compose stop` | остановить |
| `docker compose down` | остановить и удалить контейнер |
| `docker compose down -v` | то же самое, плюс удалить сертификат |

### Вариант 2 — без Docker

Нужны Python 3.9+ и `openssl` в `PATH` (в Windows он идёт вместе с Git for Windows).

```bash
python serve.py
```

Скрипт сам определит IP-адреса компьютера и выведет ссылки для открытия.

### Предупреждение о сертификате

Сертификат самоподписанный, поэтому браузер покажет предупреждение. Это нормально: нажмите «Дополнительно» → «Перейти на сайт».

## Как это работает

```
 Браузер (телефон/ПК)                                Сервер (serve.py)
 ┌───────────────────────────────────────────┐       ┌──────────────────────────┐
 │ index.html                                │◄─HTTPS┤ раздаёт index.html,      │
 │                                           │       │ jsQR.js                  │
 │ камера ─► <video> ─► <canvas> ─► jsQR() ──┼─► JSON (страница + console.log)
 │ файл ──► <img> ───► <canvas> ─┘           │       └──────────────────────────┘
 └───────────────────────────────────────────┘
```

Сервер ничего не распознаёт и не получает никаких данных: вся обработка происходит на устройстве пользователя.

## Документация по коду

### `index.html`

#### Разметка

| Элемент | id | Назначение |
|---|---|---|
| `<div class="viewer">` | `viewer` | контейнер видео, виден только пока работает камера (класс `active`) |
| `<video>` | `video` | поток с камеры (`playsinline muted`, чтобы iOS не открывал полноэкранный плеер) |
| `<div class="frame">` | — | декоративная рамка-прицел поверх видео |
| `<button>` | `scanBtn` | включает/выключает камеру |
| `<button>` | `fileBtn` | открывает выбор файла |
| `<input type="file">` | `fileInput` | скрытый input, принимает `image/*` |
| `<p>` | `status` | строка состояния; класс `error` окрашивает её в красный |
| `<pre>` | `output` | итоговый JSON |
| `<canvas>` | `canvas` | скрытый холст, через который пиксели передаются в jsQR |

#### Стили

Цвета вынесены в CSS-переменные в `:root`. Тёмная тема включается автоматически через `@media (prefers-color-scheme: dark)`. Вёрстка — одна карточка шириной до 420 px по центру, видео квадратное (`aspect-ratio: 1`).

#### Состояние

- `stream` (`MediaStream | null`) — текущий поток камеры. Если не `null`, значит камера работает. От этой переменной зависят поведение кнопки `scanBtn` и цикл `tick()`.
- `ctx` — 2D-контекст холста, создан с `willReadFrequently: true`: браузер держит буфер в оперативной памяти, и частые `getImageData` работают быстрее.

#### Функции

**`setStatus(text, isError = false)`** — пишет текст в строку состояния. Если `isError` равно true, текст становится красным.

**`toResult(raw, source)`** — собирает объект результата:

```js
{
  data: <JSON-объект, если raw — валидный JSON, иначе строка raw>,
  raw: "<исходная строка из QR>",
  source: "camera" | "image",
  scannedAt: "2026-10-12T09:00:00.000Z"   // ISO-время сканирования
}
```

Если в QR лежит JSON, его можно сразу использовать как объект через `result.data`.

**`showResult(raw, source)`** — вызывает `toResult`, превращает результат в форматированный JSON (отступ 2 пробела), выводит его в `console.log` и в `<pre id="output">`, обновляет статус.

**`decode(width, height)`** — берёт пиксели с холста (`getImageData`) и передаёт их в `jsQR(data, width, height, { inversionAttempts: "attemptBoth" })`. Опция `attemptBoth` позволяет распознавать и инвертированные коды (светлые на тёмном). Возвращает объект jsQR (`code.data` — текст, `code.location` — координаты углов) или `null`.

**`startCamera()`** (async) — прячет прошлый результат и запрашивает камеру через `navigator.mediaDevices.getUserMedia({ video: { facingMode: "environment" } })`, то есть предпочитает заднюю камеру телефона. Если доступа нет (пользователь запретил, нет HTTPS, нет камеры), показывает ошибку и выходит. Иначе подключает поток к `<video>`, показывает видео, меняет текст кнопки на «Остановить» и запускает цикл `tick()`.

**`tick()`** — цикл распознавания на `requestAnimationFrame`, то есть с частотой обновления экрана:
1. если `stream` равен `null`, цикл завершается;
2. когда у видео есть кадр (`HAVE_ENOUGH_DATA`), холст подгоняется под размер видео, кадр рисуется на холст и вызывается `decode`;
3. если код найден, камера останавливается (`stopCamera`), показывается результат, цикл завершается;
4. иначе планируется следующий кадр.

**`stopCamera()`** — останавливает все дорожки потока (гаснет индикатор камеры), обнуляет `stream` и `video.srcObject`, прячет видео и возвращает текст кнопки.

#### Обработчики событий

- `scanBtn` → `click`: если камера включена, останавливает её и очищает статус, иначе вызывает `startCamera()`.
- `fileBtn` → `click`: программно кликает по скрытому `fileInput`.
- `fileInput` → `change`: берёт выбранный файл и сразу сбрасывает `value`, чтобы можно было выбрать тот же файл ещё раз. Останавливает камеру, загружает картинку через `URL.createObjectURL`, рисует её на холсте в исходном разрешении и распознаёт. Object URL освобождается через `revokeObjectURL`. Если QR не найден, показывает ошибку.

### `serve.py`

Минимальный HTTPS-сервер, только на стандартной библиотеке (`http.server`, `ssl`). Для генерации сертификата вызывает внешний `openssl`.

#### Константы и настройки (переменные окружения)

| Константа | Переменная окружения | По умолчанию | Описание |
|---|---|---|---|
| `PORT` | `PORT` | `8443` | порт сервера |
| `ROOT` | — | папка скрипта | откуда раздаются файлы |
| `CERT_DIR` | `CERT_DIR` | `ROOT` | где лежат/создаются `cert.pem` и `key.pem` |
| `EXTRA_IPS` | `EXTRA_IPS` | пусто | IP через запятую. Если задано, используются вместо автоопределения: попадают в сертификат и в подсказку при старте. В Docker сюда передаётся `HOST_IP` |

#### Функции

**`lan_ips() -> list[str]`** — собирает IPv4-адреса компьютера двумя способами:
1. все адреса имени хоста (`socket.getaddrinfo(socket.gethostname())`);
2. адрес интерфейса, через который идёт трафик в интернет: создаётся UDP-сокет и вызывается `connect` на `8.8.8.8`. Пакеты при этом не отправляются, ОС только выбирает маршрут.

Отбрасывает loopback (`127.*`) и link-local (`169.254.*`), возвращает отсортированный список без повторов.

**`make_cert(ips)`** — вызывает `openssl req -x509` и создаёт RSA-2048 сертификат сроком на 825 дней (максимум, который принимают Apple-устройства) с CN `QR Scanner`. В `subjectAltName` попадают `localhost`, `127.0.0.1` и все переданные IP. При ошибке `openssl` выбрасывает `CalledProcessError`.

**`main()`**:
1. определяет IP: `EXTRA_IPS`, если задано, иначе `lan_ips()`;
2. если сертификата или ключа нет, создаёт `CERT_DIR` и генерирует их. Если `openssl` не найден, выходит с понятным сообщением;
3. поднимает `ThreadingHTTPServer` на `0.0.0.0:PORT` (каждый запрос обрабатывается в своём потоке) с `SimpleHTTPRequestHandler`, который раздаёт `ROOT`;
4. оборачивает сокет в TLS (`ssl.SSLContext(PROTOCOL_TLS_SERVER)`);
5. печатает ссылки для ПК и телефона и работает до `Ctrl+C`.

> ⚠️ При локальном запуске без `CERT_DIR` ключ `key.pem` лежит в раздаваемой папке, и его можно скачать по `https://<адрес>:8443/key.pem`. В локальной сети для самоподписанного сертификата это не критично, но лучше указать отдельную папку: `CERT_DIR=certs python serve.py`. В Docker ключ хранится в `/certs`, вне раздаваемой папки.

### Docker

**`Dockerfile`** — образ `python:3.12-slim`, в который через apt доставлен `openssl`. В `/app` копируются только `index.html`, `jsQR.js` и `serve.py`. Сертификат хранится в томе `/certs` (`CERT_DIR=/certs`), открыт порт 8443. `PYTHONUNBUFFERED=1` нужен, чтобы вывод `print` сразу появлялся в `docker logs`.

**`docker-compose.yml`** — сервис `qr-scanner`: проброс `8443:8443`, переменная `EXTRA_IPS` берётся из `HOST_IP` (файл `.env` или окружение), именованный том `certs` (сертификат сохраняется между перезапусками), политика `restart: unless-stopped`.

**`.dockerignore`** — не даёт попасть в образ `.git`, ключам `*.pem`, `.env` и прочим лишним файлам.

## Проверка

1. Запустить сервер и открыть страницу.
2. «Загрузить картинку с QR» → выбрать `test_qr.png`, должен появиться JSON.
3. «Сканировать QR-код» → разрешить доступ к камере и навести её на любой QR-код.

## Частые проблемы

| Симптом | Причина и решение |
|---|---|
| «Нет доступа к камере: Permission denied» | доступ запрещён: разрешите камеру в настройках сайта в браузере |
| «Нет доступа к камере» на телефоне по `http://` | нужен именно `https://` |
| Телефон не открывает страницу | устройства в разных сетях, неверный `HOST_IP` или порт 8443 закрыт брандмауэром Windows |
| QR не распознаётся с картинки | код слишком мелкий, размытый или обрезан: попробуйте снимок крупнее |
